# Курсовой проект «Пси-Эксперт»

Отчёт по дисциплине «Веб-программирование»: сайт психологического центра «Пси-Эксперт» (Django, Visual Studio 2022).

- `Отчет_курсовой_Пси-Эксперт.docx` — текст отчёта для Word
- `схемы/` — рисунки в формате draw.io (карты сайта, схема БД, шаблоны страниц, блок-схемы)
- `КАК_ПОЛЬЗОВАТЬСЯ.txt` — как вставить рисунки и что в коде сайта отсутствует

Репозиторий приватный: в отчёте есть контакты центра и учебные пароли демо-ролей.
